## 项目背景

AI在物理仿真和科学计算中的应用需要融合物理驱动和数据驱动方法。传统数值方法精度高但计算慢,深度学习快但需数据和可解释性。

**核心问题**: 如何将AI技术应用于物理仿真?

**本技能提供**: 五维模型 + 五大方法论 + 挑战机遇分析

1. **数值方法网络化**: 可微分、无需训练

## 核心原则

1. **融合思维**: 物理+数据+拟合有机结合
2. **可解释性**: 保持物理意义
3. **精度保证**: 验证精度和泛化能力
4. **角色定位**: AI加速和辅助,不追求完全替代
5. **谨慎应用**: 高精度场景需物理约束
