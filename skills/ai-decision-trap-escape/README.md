# AI决策陷阱逃离框架

> 帮助人类在AI浪潮中守住决策主导权,逃离五层陷阱,构建反脆弱职业结构。

## 项目背景

AI正在深刻改变人类的决策方式和职业发展路径。不同于以往技术仅延伸人类身体能力,AI正在延伸并重塑人类的"大脑"。它不仅改变了决策环境,更在重新定义决策的目的与意义。

**核心问题**: 如何在AI浪潮中保持自主性和核心价值?

**本技能提供**: 五层陷阱识别框架 + 五大核心方法论 + 实战策略。

## 核心框架

### 五层陷阱识别

1. **决策主体转移**: "AI说应该这样" → 人类丧失决策权
2. **身份认同危机**: "AI比我好,我没价值了" → 自我价值崩塌
3. **决策框架崩塌**: "不知道该学什么专业了" → 传统规划失效
4. **决策标准颠覆**: "AI判断比我准" → 新标准待建立
5. **思考能力萎缩**: "懒得想了,问AI吧" → 探索精神丧失

### 五大核心方法论

1. **决策主导权守卫术**: AI建议收集 → 人类判断暂停 → 人类最终签字
2. **第一性原理回归法**: 剥离AI,追问"为什么"(连续3次)
3. **反脆弱职业构建术**: 70%精力在不变能力,30%在工具技能
4. **人机协作边界设定术**: 五层任务类型,越往下AI参与度越低
5. **好奇心守护术**: 三不原则(不立刻问、不全信、不停留)

## 核心原则

1. **AI是手脚,人类是大脑**: AI负责执行,人类负责决策
2. **守住"最终签字权"**: 重大决策必须由人类明确签字
3. **追问"为什么"**: 在AI答案上不停追问,不直接接受
4. **构建反脆弱能力**: 不是选一个稳定行业,而是培养跨行业迁移能力
5. **守护好奇心**: 主动探索AI无法覆盖的领域

## 红线警示

**绝对禁止** ❌:
- 将人生重大决策完全交给AI (婚姻、职业、医疗)
- 在AI建议上停止追问"为什么"

**必须由人类主导** ✅:
- 道德和伦理判断
- 人生意义追寻
- 对他人的同理心和理解
