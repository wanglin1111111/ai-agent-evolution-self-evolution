# AI决策陷阱逃离框架 - 测试案例集

## 测试案例1: 职业选择决策

**场景**: 小王是一名大三学生,专业是市场营销,听说AI会取代营销工作,正在考虑转专业。

**测试任务**: 使用本技能帮助小王做出决策。

**预期输出**:
1. 识别陷阱层: **决策框架崩塌** ("不知道该学什么专业了")
2. 应用方法: **第一性原理回归法**
   - Q1: 剥离AI,小王真正想要的是什么? → "有意义的职业,能与人建立联系"
   - Q2: 为什么想要这个? → "我喜欢理解人的需求"
   - Q3: 这个目标在AI时代是否仍然有意义? → **有意义** (AI无法替代人际理解)
   - Q4: 如何用AI加速而非替代? → "用AI分析数据,我用洞察做决策"
3. 建议输出:
   ```
   不必转专业。营销的核心价值是"理解人",AI擅长数据分析但不擅长人际洞察。
   建议: 强化人际理解能力、创意策划能力,将AI作为数据分析工具。
   投入70%精力在"不可替代层",30%精力在"AI协作技能"。
   ```

**验证标准**:
- [x] 正确识别陷阱层
- [x] 应用至少一个核心方法
- [x] 输出包含"决策主导权"强调
- [x] 输出包含"反脆弱职业"建议

## 测试案例2: 投资决策

**场景**: 李先生让ChatGPT分析某只股票,ChatGPT给出"强烈推荐买入"的结论,李先生准备直接买入。

**测试任务**: 使用本技能帮助李先生守住决策主导权。

**预期输出**:
1. 识别陷阱层: **决策主体转移** ("AI说应该这样")
2. 应用方法: **决策主导权守卫术**
   - Step1: AI建议收集 → 已完成 (ChatGPT分析)
   - Step2: 人类判断暂停 → 强制李先生等待,不立刻决策
   - Step3: 人类最终签字 → 要求李先生写下:
     ```
     我决定买入这只股票,理由是:
     1. 我认可AI分析的基本面数据
     2. 该公司符合我的投资理念(长期价值投资)
     3. 我的风险承受能力可以接受可能的亏损
     最终决策: 李先生 (日期: 2026-05-25)
     ```
3. 追问引导:
   ```
   Q: "如果ChatGPT不存在,你会买这只股票吗?"
   Q: "你的投资理念是什么?这只股票是否符合?"
   Q: "你能接受的最大亏损是多少?"
   ```

**验证标准**:
- [x] 正确识别陷阱层
- [x] 应用决策主导权守卫术
- [x] 引导用户追问"为什么"
- [x] 要求用户明确写下决策理由

## 测试案例3: 创作者焦虑

**场景**: 张作家看到郑渊洁案例(AI 4秒模仿30年风格),担心自己的写作价值被AI取代,产生"我还有什么价值"的焦虑。

**测试任务**: 使用本技能帮助张作家重构身份认同。

**预期输出**:
1. 识别陷阱层: **身份认同危机** ("AI比我好,我没价值了")
2. 应用策略: **郑渊洁案例启示录**
   - AI擅长"风格复制",不擅长"风格创造"
   - 人类作家的价值在于"为什么要这样写"
3. 重构身份认同:
   ```
   从"我是写小说的人" → "我是通过故事传递价值观的人"
   技能层(如何写得好)可以交给AI优化
   价值层(为什么写、写什么主题)必须由人类主导
   ```
4. 好奇心守护建议:
   ```
   每月自查:
   - [ ] 我是否提出了一个AI想不到的问题?
   - [ ] 我是否在某个主题建立了独立于AI的见解?
   ```

**验证标准**:
- [x] 正确识别陷阱层
- [x] 应用郑渊洁案例启示录
- [x] 重构身份认同
- [x] 提供好奇心守护建议

## 测试案例4: 学习路径选择

**场景**: 陈工程师想学编程,听说AI会写代码,犹豫是否值得投入时间学Python。

**测试任务**: 使用本技能帮助陈工程师做出学习决策。

**预期输出**:
1. 识别陷阱层: **决策标准颠覆** ("不知道什么是好的标准了")
2. 应用方法: **反脆弱职业构建术**
   ```
   第一层(不变能力): 算法思维、逻辑推理 ← 投入70%
   第二层(迁移能力): 学习力、问题解决力 ← 投入70%
   第三层(工具技能): Python语法、具体实现 ← 投入30%
   ```
3. 建议:
   ```
   学编程的底层逻辑不会过时,但实现方式可以交给AI。
   建议: 学习算法思维和逻辑推理(第一层),用AI辅助实现层(第三层)。
   不必精通Python语法,但必须掌握"如何用代码解决问题"的思维。
   ```
4. 执行清单:
   ```
   - [ ] 学习算法基础(第一层)
   - [ ] 培养问题拆解能力(第二层)
   - [ ] 用AI辅助代码实现(第三层)
   - [ ] 定期评估第三层技能的"可自动化指数"
   ```

**验证标准**:
- [x] 正确识别陷阱层
- [x] 应用反脆弱职业构建术
- [x] 提供三层架构建议
- [x] 包含"可自动化指数"评估建议

## 测试案例5: 人机协作边界设定

**场景**: 刘设计师想用AI设计一个医疗诊断界面,询问是否应该让AI主导设计。

**测试任务**: 使用本技能帮助刘设计师设定人机协作边界。

**预期输出**:
1. 识别任务类型: **价值决策类** (医疗诊断涉及患者健康)
2. 应用方法: **人机协作边界设定术**
   ```
   医疗诊断界面设计属于"价值决策类":
   - AI角色: 信息 (分析用户需求、提供设计选项)
   - 人类角色: 决策 (判断哪个设计对患者更友好)
   
   禁止AI主导:
   - 道德判断 (是否对患者隐私充分保护)
   - 同理心设计 (理解患者的焦虑情绪)
   ```
3. 执行建议:
   ```
   Step1: 用AI分析患者需求,生成多个设计选项
   Step2: 人类设计师基于同理心选择最佳方案
   Step3: 人类设计师判断隐私保护是否充分
   Step4: 人类最终签字: "我选择方案X,理由是..."
   ```

**验证标准**:
- [x] 正确识别任务类型
- [x] 应用人机协作边界设定术
- [x] 明确AI角色和人类角色
- [x] 强调禁止AI主导道德判断
