# 教育创业协同框架

> 将教育热情与创业思维融合,通过同理心、自我认知和资源整合构建可持续的教育创业路径

## 项目背景

教育创业不是做生意,是使命驱动的持续学习。传统创业思维(产品→市场→利润)不适用于教育领域,需要转向(热情→连接→价值→可持续)的价值驱动模式。

**核心问题**: 如何在教育创业中保持初心、整合资源、建立连接?

**本技能提供**: 三维模型 + 五大方法论 + 实战工具箱

## 核心框架

### 教育创业三维模型

1. **初心驱动**: 从热情到使命(不为数据,为价值)
2. **资源整合**: 发现问题→调动资源→实现目标
3. **同理心连接**: 理解用户、团队、自己

### 五大核心方法论

1. **教育创业MVP快速验证法**: 最小场景,快速迭代
2. **教育趋势洞察与定位法**: 识别趋势,找到蓝海
3. **AI赋能教育创业效率法**: 自动化重复任务,保持人性温度
4. **持续学习循环法**: 从"教师"到"学习者"心态转变
5. **同理心驱动的产品迭代法**: 深度理解用户真实需求

1. **初心驱动**: 不为数据增长,为帮助特定群体成长
2. **同理心优先**: 理解用户真实需求,不假设需求
3. **资源整合**: 识别优势,整合互补资源,建立交换机制
4. **持续学习**: 从"教师"到"学习者"心态转变
5. **保持温度**: AI解放人力,人做连接工作
