# 教育创业协同框架 - 测试案例集

## 测试案例1: 儿童咖啡创业项目

**场景**: 10岁小明想尝试创业,家长不知道如何引导。

**测试任务**: 使用教育创业MVP快速验证法设计项目。

**预期输出**:
1. 定义最小教育场景:
   ```
   项目: 周末集市卖咖啡
   学生数: 小明独自,家长辅助
   周期: 1天(周六上午)
   验证核心: 小明能否主动发现问题并调整策略
   ```

2. 设计验证指标:
   ```
   量化指标:
   - 销售量: 目标10杯
   - 成本计算: 小明是否理解成本
   - 利润计算: 小明是否计算利润

   质化指标:
   - 问题发现: 小明是否主动提出改进想法
   - 策略调整: 遇到困难是否尝试调整
   - 成就感: 小明是否体验到解决问题的喜悦
   ```

3. 低成本执行:
   ```
   成本: 咖啡豆($5) + 纸杯($3) = $8
   场地: 社区集市免费摊位
   执行: 小明制作咖啡,家长辅助收银
   ```

4. 快速迭代:
   ```
   第一轮: 8:00-10:00,卖3杯
   问题: 人流量少,价格太高($3/杯)
   
   小明提出改进:
   - 调整时间: 9:00-11:00(人多时段)
   - 调整价格: $2/杯
   - 调整位置: 移到入口处
   
   第二轮: 卖7杯,盈利$6
   ```

**验证结果**:
- ✅ 小明主动发现问题(人流量少、价格高)
- ✅ 小明提出调整策略(时间、价格、位置)
- ✅ 小明理解成本和利润($8成本, $14收入, $6利润)
- ✅ 小明体验到成就感("我赚到了钱!")

**验证标准**:
- [x] MVP四步法完整应用
- [x] 验证指标量化+质化
- [x] 低成本执行成功
- [x] 孩子主动迭代改进

## 测试案例2: 教育数据平台AI应用

**场景**: 国际学校老师需要收集学生数据,传统方式耗时1周。

**测试任务**: 使用AI赋能教育创业效率法解决问题。

**预期输出**:
1. 识别重复性任务:
   ```
   任务: 收集学生学习数据
   传统方式: 手动填写表格,整理汇总
   时间成本: 1周
   问题: 耗时长,易出错,不及时
   ```

2. 应用AI自动化:
   ```
   AI工具: Google Forms + 自动汇总脚本
   改进方式:
   - 老师发送在线问卷链接
   - 学生/家长填写数据
   - AI自动汇总生成报告
   时间成本: 1夜 (数据收集+汇总)
   ```

3. 保持教育温度:
   ```
   AI承担: 数据收集、汇总整理
   教师聚焦:
   - 分析异常数据
   - 关注需要帮助的学生
   - 与学生/家长深度沟通
   ```

4. 应用同理心三问迭代:
   ```
   Q1: 用户真实需要什么?
   - 不仅省时间,还需发现学生问题
   
   Q2: 为什么不满意?
   - 数据分散,无法及时发现变化
   
   Q3: 如果我是老师,我需要什么?
   - 一键报告 + 异常标注 + 学生关注提醒
   
   迭代结果:
   从"数据收集工具" → "学生发展洞察平台"
   ```

**验证标准**:
- [x] AI自动化应用成功
- [x] 时间从1周缩短到1夜
- [x] 保持教育温度(教师聚焦深度沟通)
- [x] 同理心迭代产品优化

## 测试案例3: 教育创业初心验证

**场景**: 张老师想创业做"高端数学辅导班",但不确定初心是否正确。

**测试任务**: 使用初心验证方法帮助张老师澄清方向。

**预期输出**:
1. 应用三问法:
   ```
   Q1: 如果不赚钱,你还会做这件事吗?
   张老师回答: "会的,我喜欢教数学"
   → 初心验证通过
   
   Q2: 你是为谁服务?他们的真实需求是什么?
   张老师回答: "为成绩不好的学生"
   → 需深入调研: 为什么成绩不好?真实需求是什么?
   
   Q3: 5年后你希望看到什么改变?
   张老师回答: "帮助更多学生提高成绩"
   → 需深化: 提高成绩是为了什么?长远愿景是什么?
   ```

2. 初心类型判断:
   ```
   张老师当前初心:
   - ✅ 热情: 喜欢教数学
   - ⚠️ 价值: "提高成绩"(可能过于实用主义)
   - ⚠️ 愿景: 缺乏长期愿景
   
   建议:
   - 深入理解学生为什么成绩不好
   - 从"提高成绩"转向"培养数学思维"
   - 建立长期愿景: "让更多学生爱上数学"
   ```

3. 同理心访谈验证:
   ```
   访谈目标学生:
   - "你觉得数学难在哪里?"
   - "你希望数学课是什么样的?"
   
   发现真实需求:
   - 学生不是"成绩不好",而是"害怕数学"
   - 学生需要"不焦虑的学习环境"
   - 学生需要"看到数学的有趣应用"
   
   调整初心:
   从"提高成绩" → "帮助害怕数学的学生爱上数学"
   ```

**验证标准**:
- [x] 应用三问法验证初心
- [x] 识别初心潜在问题
- [x] 同理心访谈发现真实需求
- [x] 调整初心更聚焦价值

## 测试案例4: 教育创业资源整合

**场景**: 王老师想做一个"儿童创造力工作坊",但缺乏场地、资金、团队。

**测试任务**: 使用资源整合策略帮助王老师实现想法。

**预期输出**:
1. 识别自身优势:
   ```
   王老师擅长:
   - ✅ 教学: 10年小学教师经验
   - ✅ 课程设计: 有创造力培养经验
   
   王老师认识:
   - ✅ 专家: 心理学教授(朋友)
   - ✅ 场地: 社区活动中心(可借用)
   
   王老师有:
   - ⚠️ 时间: 每周六可用
   - ❌ 资金: 缺乏启动资金
   - ❌ 团队: 需要助手
   ```

2. 寻找互补资源:
   ```
   缺失能力: 营销推广
   解决: 找营销合伙人(家长志愿者)
   
   缺失资金: 启动成本
   解决: 申请社区公益基金
   
   缺失团队: 助手
   解决: 培训家长志愿者,利益共享
   ```

3. 建立资源交换机制:
   ```
   价值交换:
   - 王老师提供: 课程设计+教学
   - 家长志愿者提供: 营销推广+助手
   - 社区提供: 场地+公益基金
   
   利益共享:
   - 王老师: 实现教育理想,建立品牌
   - 家长: 孩子免费参与,获得成长
   - 社区: 提升服务品质,获得口碑
   ```

4. MVP验证:
   ```
   最小场景: 6个孩子,2小时,周六上午
   验证指标: 孩子是否主动尝试新想法
   执行成本: 低(场地免费,家长志愿)
   第一期效果: 孩子提出3个创新想法
   
   迭代: 根据反馈调整课程内容
   ```

**验证标准**:
- [x] 识别自身优势完整
- [x] 寻找互补资源成功
- [x] 建立资源交换机制
- [x] MVP验证可行性

## 测试案例5: 从"教师"到"学习者"心态转变

**场景**: 李老师创业2年,感觉遇到瓶颈,不知道如何突破。

**测试任务**: 使用持续学习循环法帮助李老师突破瓶颈。

**预期输出**:
1. 心态诊断:
   ```
   李老师当前心态:
   - ❌ "我是专家,我知道什么对学生最好"
   - ❌ 固化思维,缺乏创新
   - ❌ 听不进学生/家长反馈
   
   问题: 缺乏"学习者心态"
   ```

2. 心态转变:
   ```
   从"教师" → "学习者":
   - 我是学习者,学生和家长是我的老师
   - 每次互动都是学习机会
   - 保持好奇心和开放性
   ```

3. 学习循环实践:
   ```
   观察:
   - 课后观察学生反应
   - 观察哪些内容学生最感兴趣
   
   提问:
   - 问学生: "今天学到了什么?哪里可以更好?"
   - 问家长: "孩子回家后分享了什么?"
   
   实验:
   - 尝试新的教学方法
   - 测试不同的课程内容
   
   反思:
   - 每周复盘: 什么有效?什么无效?
   - 每月反思: 我学到了什么?
   
   调整:
   - 根据反馈优化课程
   - 放弃无效方法
   
   再观察: 循环持续
   ```

4. 具体突破:
   ```
   李老师瓶颈: 学生参与度下降
   
   学习循环应用:
   - 观察: 学生对理论讲解不感兴趣
   - 提问: 学生喜欢动手实践
   - 实验: 增加50%实践环节
   - 反思: 参与度提升30%
   - 调整: 继续增加实践比重
   
   结果: 突破瓶颈,学生满意度提升
   ```

**验证标准**:
- [x] 心态诊断准确
- [x] 心态转变成功
- [x] 学习循环完整实践
- [x] 突破瓶颈有效
