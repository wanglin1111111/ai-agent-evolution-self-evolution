## 核心原则

1. **艺术是灵魂**: 尊重原创性,不牺牲艺术表达
2. **科技是工具**: 批判性使用AI,理解局限
3. **商业是放大器**: 公平分配价值,长期合作
4. **学会学习**: 持续学习能力最重要
5. **批判性思维**: AI工具使用的关键

## 三大核心认知

**认知1: AI是工具,需批判性使用**
- AI = 锤子,有力但非万能
- 理解原理+理解局限+批判思维

**认知2: 学会学习是最重要的能力**
- 知识积累 < 技能掌握 < 学会学习 < 批判思维

**认知3: 艺术与商业不是对立面**
- 传统: 艺术≠商业
- 融合: 艺术×商业 (协同放大)
