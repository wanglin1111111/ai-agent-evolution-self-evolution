# AI健康智能框架 - 快速参考卡片

## 🎯 核心隐喻
**AI是健康管理的超级助手,不是医生的替代者**
```
传统: 体检报告 → 医生解读 → 被动治疗
AI时代: 持续监测 → AI洞察 → 主动预防
```

## 🔍 AI健康智能三维模型

| 维度 | 传统模式 | AI模式 | 核心转变 |
|------|---------|--------|---------|
| **数据分析** | 群体标准 | 个体基线 | 个性化评估 |
| **睡眠监测** | 数据记录 | 洞察优化 | 行为改变 |
| **生活习惯** | 知识传递 | 行为干预 | 习惯养成 |

## 🛠️ 核心方法论速查

### 方法1: AI健康数据安全三原则
```
原则1: 数据最小化 (只收集必要数据)
原则2: 本地处理优先 (敏感数据不上云)
原则3: 用户控制权 (随时可删除数据)
```

### 方法2: AI健康洞察生成法
```
四步法:
数据整合 → 模式识别 → 因果推断 → 洞察表达

案例: 整合睡眠+运动数据 → 发现运动改善睡眠 → 验证因果关系 → "每周运动3次,深睡提升15%"
```

### 方法3: AI健康预警机制
```
三级预警:
绿色(正常): 数据在基线范围内
黄色(注意): 数据偏离基线,建议调整
红色(危险): 数据显著异常,建议就医

设计原则:
- 避免过度预警
- 提供明确行动建议
- 区分"关注"和"就医"
```

### 方法4: 健康行为干预设计法
```
五原则:
1. 个性化 (基于个人数据)
2. 渐进式 (小步快跑)
3. 情境感知 (考虑当前情境)
4. 正向激励 (强调收益)
5. 可验证 (提供效果验证)
```

### 方法5: AI与医生协作边界
```
AI擅长: 监测、预警、习惯优化、教育、预测
医生擅长: 诊断、治疗、复杂判断、处方、紧急处理

边界: AI发现异常 → 建议就医
红线: AI不提供诊断结论
```

## ⚠️ 三级预警示例

| 预警级别 | 数据示例 | 行动建议 |
|---------|---------|---------|

| **红色** | 静息心率95(基线65) | 建议就医 |
