# AI健康智能框架

> AI在医疗健康领域的应用,包括个性化数据分析、睡眠监测、生活习惯优化,帮助用户通过AI获得健康洞察,同时保护隐私与数据安全

## 项目背景

传统健康管理依赖体检报告和医生解读,存在滞后性和被动性问题。AI可以持续监测、主动预警、个性化优化,但需明确AI不是医生的替代者。

**核心问题**: 如何用AI赋能健康管理,同时保护隐私和明确边界?

**本技能提供**: 三维模型 + 五大方法论 + 实战策略

## 核心框架

### AI健康智能三维模型

1. **个性化数据分析**: 从群体标准到个体基准
2. **睡眠监测与优化**: 从记录到洞察
3. **生活习惯优化**: 从知识到行为改变

### 五大核心方法论

1. **AI健康数据安全三原则**: 数据最小化/本地处理/用户控制
2. **AI健康洞察生成法**: 数据整合→模式识别→因果推断→洞察表达
3. **AI健康预警机制**: 三级预警(绿/黄/红)
4. **健康行为干预设计法**: 五原则(个性化/渐进式/情境感知/正向激励/可验证)
5. **AI与医生协作边界设定**: 明确分工,红线警示

## 核心原则

1. **AI是助手,不是替代者**: 不提供诊断结论
2. **个性化评估**: 建立个体基线,而非群体标准
3. **隐私保护**: 数据最小化,本地处理,用户控制
4. **主动预防**: 从被动治疗到主动预防
5. **明确边界**: AI发现异常,建议就医

## 与其他技能协同
